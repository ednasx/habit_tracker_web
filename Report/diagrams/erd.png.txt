## What This Diagram Should Show

Entity Relationship Diagram (ERD) showing all database tables, columns, relationships, and constraints.

## Tables to Include

### 1. auth.users (Supabase Auth)
- id (uuid, PK)
- email (text)
- encrypted_password (text)
- created_at (timestamptz)

### 2. user_profiles
- user_id (uuid, PK, FK → auth.users.id)
- username (text, UNIQUE, NOT NULL)
- display_name (text)
- created_at (timestamptz)
- updated_at (timestamptz)

### 3. habits
- id (bigserial, PK)
- user_id (uuid, FK → auth.users.id, NOT NULL)
- name (text, NOT NULL)
- description (text)
- created_at (timestamptz)
- archived (boolean)

### 4. habit_logs
- id (bigserial, PK)
- habit_id (bigint, FK → habits.id, NOT NULL)
- user_id (uuid, FK → auth.users.id, NOT NULL)
- date (date, NOT NULL)
- value (integer, NOT NULL)
- created_at (timestamptz)
- UNIQUE (habit_id, date)

### 5. habit_stats
- habit_id (bigint, PK, FK → habits.id)
- user_id (uuid, PK, FK → auth.users.id)
- total_completions (integer, NOT NULL)
- current_streak (integer, NOT NULL)
- longest_streak (integer, NOT NULL)
- last_completed_date (date)

### 6. friends
- user_id (uuid, PK, FK → auth.users.id)
- friend_id (uuid, PK, FK → auth.users.id)
- status (text, NOT NULL, CHECK)
- created_at (timestamptz)
- updated_at (timestamptz)

## Relationships

### One-to-One (1:1)
- auth.users → user_profiles
- habits → habit_stats

### One-to-Many (1:N)
- auth.users → habits
- auth.users → habit_logs
- habits → habit_logs

### Many-to-Many (M:N)
- user_profiles ↔ friends (self-referential)

## Constraints to Show

### Primary Keys
- Mark with PK label or key icon
- Bold or different color

### Foreign Keys
- Show with arrows
- Label with FK
- Show ON DELETE CASCADE

### Unique Constraints
- user_profiles.username

### Check Constraints

- Mark required fields

## How to Create

### Option 1: dbdiagram.io (RECOMMENDED)
1. Go to https://dbdiagram.io/
2. Use DBML syntax (see below)
3. Export as PNG

**DBML Code:**
```
Table auth_users {
  id uuid [pk]
  email text
  encrypted_password text
  created_at timestamptz
}

Table user_profiles {
  user_id uuid [pk, ref: > auth_users.id]
  username text [unique, not null]
  display_name text
  created_at timestamptz
  updated_at timestamptz
}

Table habits {
  id bigserial [pk]
  user_id uuid [ref: > auth_users.id, not null]
  name text [not null]
  description text
  created_at timestamptz
  archived boolean
}

Table habit_logs {
  id bigserial [pk]
  habit_id bigint [ref: > habits.id, not null]
  user_id uuid [ref: > auth_users.id, not null]
  date date [not null]
  value integer [not null]
  created_at timestamptz
  
  Indexes {
    (habit_id, date) [unique]
  }
}

Table habit_stats {
  habit_id bigint [pk, ref: > habits.id]
  user_id uuid [pk, ref: > auth_users.id]
  total_completions integer [not null]
  current_streak integer [not null]
  longest_streak integer [not null]
  last_completed_date date
}

Table friends {
  user_id uuid [pk, ref: > auth_users.id]
  friend_id uuid [pk, ref: > auth_users.id]
  status text [not null, note: 'pending, accepted, rejected']
  created_at timestamptz
  updated_at timestamptz
}
```

### Option 2: draw.io
1. Go to https://app.diagrams.net/
2. Use Entity Relationship template
3. Add tables as boxes
4. Add columns with data types
5. Draw relationships with crow's foot notation
6. Export as PNG

### Option 3: Generate from Database
1. Connect to Supabase with DBeaver
2. Right-click database → Generate ER Diagram
3. Export as PNG

### Option 4: Supabase Table Editor
1. Open Supabase dashboard
2. Go to Table Editor
3. Take screenshot of schema view
4. Annotate with relationships
