# PLACEHOLDER: security-flow.png

## What This Diagram Should Show

The security model and request flow for authenticated API requests, showing all security layers.

## Security Layers to Visualize

### Layer 1: TLS/HTTPS Encryption
- Browser → Nginx Ingress (HTTPS)
- TLS certificate from Let's Encrypt
- Encrypted in transit

### Layer 2: JWT Authentication
- User logs in → Supabase Auth
- Supabase issues JWT
- Frontend includes JWT in Authorization header
- Backend verifies JWT signature

### Layer 3: API Authorization
- requireAuth middleware
- Extracts user_id from JWT
- Attaches to req.user

### Layer 4: Row-Level Security (RLS)
- Database policies filter by user_id
- Automatic query filtering
- Defense in depth

### Layer 5: Input Validation
- Server-side validation
- Sanitization
- SQL injection prevention
- XSS protection

## Request Flow Diagram

### Authenticated Request Flow
```
1. Browser
   ↓ HTTPS Request
   ↓ Authorization: Bearer <JWT>
2. Nginx Ingress (TLS Termination)
   ↓ HTTP Request (internal)
3. Habit Service (requireAuth middleware)
   ↓ Verify JWT signature
   ↓ Extract user_id from sub claim
4. Route Handler
   ↓ Query database with user_id filter
5. Supabase (Service Role)
   ↓ Execute query (RLS bypassed by service role)
   ↓ Return results
6. Route Handler
   ↓ JSON Response
7. Nginx Ingress
   ↓ HTTPS Response (encrypted)
8. Browser
```

### Unauthorized Request Flow
```
1. Browser (no JWT)
   ↓ HTTPS Request (no Authorization header)
2. Nginx Ingress
   ↓ HTTP Request
3. Habit Service (requireAuth middleware)
   ↓ No Authorization header
   ↓ ❌ Return 401 Unauthorized
4. Browser
   ↓ Show login page
```

## Visual Elements

**Components:**
- Browser (icon)
- Nginx Ingress (box with lock icon)
- Habit Service (box)
- User Service (box)
- Supabase Auth (box)
- Supabase Database (cylinder)

**Security Indicators:**
- Lock icons for HTTPS
- Key icons for JWT
- Shield icons for RLS
- Checkmark for validation

**Color Coding:**
- Green arrows = Authorized
- Red arrows = Unauthorized
- Blue boxes = Security layers

## How to Create

### Option 1: Sequence Diagram
1. Use Mermaid or PlantUML
2. Show time-based flow
3. Include security checks
4. Render to PNG

### Option 2: Layered Diagram
1. Use draw.io
2. Show security layers as horizontal bands
3. Request flows through each layer
4. Export as PNG
