# Habit Tracker Web

A web-based habit tracking application built for the **Design of Dynamic Web Systems** course.

The goal is to provide:
- Habit creation and management
- Daily logging of habits
- Progress / streak visualizations
- (Later) Social and analytics features

---

## Tech stack (planned)

- **Frontend**: React (Vite)
- **Backend**: Node.js / Express (microservices)
- **Database**: Supabase (PostgreSQL)
- **Infra / DevOps**: Docker, Kubernetes, Helm, GitHub Actions

At the moment, this repository contains the **frontend**. Backend and infra will be added later.
